# Acervo Manager

Sistema de Gestão de Biblioteca desenvolvido para facilitar o cadastro, consulta, empréstimo e devolução de livros.

## 1. Arquitetura

O sistema é dividido em três principais componentes:

- **Frontend:** Angular
- **Backend:** Node.js + Express
- **Banco de Dados:** MySQL

A comunicação entre frontend e backend é realizada através de uma API REST utilizando HTTP.

## 2. Tecnologias

- Angular
- Tailwind CSS
- Node.js
- Express
- MySQL
- API REST
- HTTP

## 3. Funcionalidades

- Cadastro e consulta de livros
- Cadastro e consulta de usuários
- Registro de empréstimos
- Registro de devoluções
- Consulta da disponibilidade dos livros

## 4. Desenvolvimento (Frontend)

Este projeto foi gerado com o Angular CLI.

### Servidor de Desenvolvimento

Para iniciar o servidor local, execute:

```bash
ng serve
```
